## Project Overview

This web page was made so it can be viewed and be responsive. This allows it to be displayed correctly on popular screen sizes. WTWR web page shows curent weather temps and location. Users can click on an item and it will give you sugestions based on current temperature. The web page also includes functionality to add clothes.

## Features

- Current Weather: API integration give live weather temperture and location.
- Items can be selected: When items are selected, sugestions are made base on temperture.
- Responsive Layout: It is designed to work well on both desktop and mobile devices.
- Buttons: Gives you options to add clothes.

## Technologies

HTML, CSS, JavaScript, Vite, git use in the website, using responsive design techniques to ensure it looks good on all devices.
